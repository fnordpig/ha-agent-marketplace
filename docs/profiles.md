# Profiles

## Safe Observer

Plugins: `ha-foundation-skills`, optional `homeassistant-ai-skills`, `ha-context-official`.

Use for reading exposed state/context and understanding a Home Assistant instance through the official MCP boundary.

## Builder

Plugins: `ha-foundation-skills`, optional `homeassistant-ai-skills`, `ha-config-ha-mcp`, `ha-dashboard-designer`, `ha-review-gates`.

Use for authoring proposed automations, helpers, scripts, and dashboards with review gates.

## Power User

Plugins: `ha-foundation-skills`, optional `homeassistant-ai-skills`, `ha-config-ha-mcp`, `ha-repo-poweruser`, `ha-dashboard-designer`, `ha-review-gates`.

Use for repo-first YAML refactoring and dependency scanning.

## Live Deployer

Plugins: `ha-foundation-skills`, optional `homeassistant-ai-skills`, `ha-deploy-vibecode`, `ha-review-gates`.

Use only when the user has approved live deployment and rollback requirements are met.

## Full Power

Plugins: all marketplace plugins.

Use only when the operator accepts both repo mutation and live deployment risk.
